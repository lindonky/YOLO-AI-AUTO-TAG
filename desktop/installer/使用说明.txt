YOLO Auto-Tag 使用说明
版本：V1.1

一、首次启动
1. 双击桌面上的“YOLO Auto-Tag”。
2. 填写自己的中转站 URL、API Key 和中转站支持的视觉模型名称。
3. 中转站首页或 /v1 基础地址会自动补全 /v1/chat/completions；已有自定义聊天路径保持不变。
4. 如需 Mihomo 代理，可填写 http://127.0.0.1:7897；否则留空。
5. 点击“保存并测试”。Key 保存后输入框为空是正常的，表示继续使用 DPAPI 加密保存的 Key。

二、图片标注
1. 导入图片，填写目标描述和类别名称。
2. 用“示例教学”框选代表图片；每次画框前在“新框类别”选择对应类别，再保存示例。
3. 点击“开始分析”，完成后逐张检查框和复核状态。
4. 默认开启逐类漏检复核，有目标图片会多一次请求，可在设置关闭。异常图片会保留到 error，不能当背景负样本训练。

三、视频标注
1. 导入视频并设置抽帧参数。
2. 开始分析后检查时间轴结果。
3. 可导出抽帧图片、YOLO TXT、classes.txt 或带框视频。

四、注意事项
- 4K 分块复核会增加 API 调用次数和费用。
- AI 可能漏检、误检或框选偏移，正式训练前仍需人工抽查。
- 不要把真实 API Key、私人图片、视频或标注数据上传到公开仓库。

配置：%LOCALAPPDATA%\YOLOAutoTag\settings.json
日志：%LOCALAPPDATA%\YOLOAutoTag\logs\desktop.log
项目仓库：https://github.com/lindonky/YOLO-AI-AUTO-TAG

V1.1 升级提示：
- 原 API Key 和模型配置会保留。请将模型确认为服务商当前可用的视觉模型，例如已实测的 gemini-3.8-flash-low。
- 正常图、背景图、异常图分别导出；error 的空 TXT 只是占位，不能混入背景训练。
