YOLO Auto-Tag 使用说明
版本：V1.2.7

一、首次启动
1. 双击桌面上的“YOLO Auto-Tag”。
2. 填写自己的中转站 URL、API Key 和中转站支持的视觉模型名称。
3. 中转站首页或 /v1 基础地址会自动补全 /v1/chat/completions；已有自定义聊天路径保持不变。
4. 如需 Mihomo 代理，可填写 http://127.0.0.1:7897；否则留空。
5. 点击“保存并测试”。Key 保存后输入框为空是正常的，表示继续使用 DPAPI 加密保存的 Key。
6. Gemini 可勾选“自动选择”，用“保存并检测 Gemini”查看图片小样结果。检测会产生 API 费用，可停止；Pro 回退默认关闭。
7. 自动模式会优先使用已通过且未过期的模型，遇到路由故障或读取超时限次切换；鉴权、额度问题会停止批次；限流先统一退让重试。实际请求模型记录在导出清单 modelsUsed 中。
8. “最大并发请求数”可设 1—60，默认 10，统一约束模型检测、识别和复核；保存后生效。调低时正在执行的请求继续结束，新请求排队。每分钟请求上限单独设置，0 为自动退让；默认不再固定为每分钟 60 次。

二、图片标注
1. 导入图片，填写目标描述和类别名称。
2. 用“示例教学”框选代表图片；每次画框前在“新框类别”选择对应类别，再保存示例。
3. 点击“开始分析”，完成后逐张检查框和复核状态。手动结束时等待当前请求返回，再进入相同的人工复核流程；未识别图片保留为 error。
4. 默认开启逐类漏检复核，有目标图片会多一次请求，可在设置关闭。异常图片会保留到 error，不能当背景负样本训练。

三、视频标注
1. 导入视频并设置抽帧参数。
2. 开始分析后检查时间轴结果。
3. 可导出抽帧图片、YOLO TXT、classes.txt 或带框视频。

四、注意事项
- 4K 分块复核会增加 API 调用次数和费用。
- AI 可能漏检、误检或框选偏移，正式训练前仍需人工抽查。
- 不要把真实 API Key、私人图片、视频或标注数据上传到公开仓库。

日志：%LOCALAPPDATA%\YOLOAutoTag\logs\desktop.log
项目仓库：https://github.com/lindonky/YOLO-AI-AUTO-TAG

V1.2.7 升级提示：
- 原 API Key 和手动模型配置会保留；自动选择需自行勾选并保存。服务商模型目录与实际可用性可能不同，请以当前图片小样检测为准。
- 正常图、背景图、异常图分别导出；error 的空 TXT 只是占位，不能混入背景训练。

V1.2.7 提速与恢复：
- 图片任务持续并行补位，各图独立画布、提示与结果；本地异步代理避免浏览器长连接限制上游并发。
- 请求、复核、探测与重试统一计数和限速；限流时遵循 Retry-After，持续超时降低并发，稳定后逐步恢复。
- JSON 不完整、截断或类别/坐标不合要求时重新请求完整结果；额外重试可设为 0—10 次，默认 2；每个阶段首次请求与网络/JSON 重试共用 1 + 重试次数的预算，不叠加后台 429 重试。图片小样与模型目录属于单独请求，统一计入总并发与请求数。
- 多次格式失败仅将当前图片保留到 error，继续其他图片；不会将残缺 JSON 当作背景。
- 手动结束会取消排队请求，已发出的调用结束后保留结果并进入人工复核。

V1.2.7 结果查看与断线恢复：
- 右侧裁剪预览和时间轴互斥打开；缩略图可点击放大并定位原图。
- 时间轴可搜索文件名、类别、图片数字；可按文件名、图片序号升降序、完成顺序排序。
- 设置中可选“识别图片数字”，每图额外请求一次，保留前导零；不确定的数字不参与序号排序，可人工更正。已有完成标注可补识别数字，无需重新检测目标。
- 连接中断先退避重试。仍失败时暂停新任务并检测当前服务图片小样，由用户选择模型继续、原配置重试或结束进入人工复核。
- 使用所选模型继续会保存为手动模型，避免自动模式立即选择回原来的模型。检测与重试均计入统一限速，可能产生额外 API 费用。

V1.2.7 本机诊断与 MCP：
- 同目录 YOLOAutoTagMCP.exe 支持标准 MCP stdio；--list 查看工具，--call app_status 读取版本和任务状态。
- 可读取当前任务、失败图片、框、图片预览与脱敏请求记录，并导入小批图片、启动、暂停、结束、检测或切换模型。
- 接口仅在本机开放，凭据使用 DPAPI 保存；不提供任意代码执行或读取 API Key 的工具。
- requests.jsonl 记录中转真实状态与本地处理状态，区分中转 409 和本地任务取消；本地取消注明原因。
- 中转临时 409 进入有限重试与恢复流程；任务已取消的本地 409 不重复请求。

V1.2.7 API 支持：
- 可保存最多 20 项服务，每项拥有独立的 URL、Key、协议和模型列表。
- DeepSeek 官方预设为 deepseek-v4-flash，也可使用 deepseek-flash。V4 Pro 当前不支持图片输入。
- 支持首页、/v1、完整 chat/completions、responses、messages 和 anthropic 基础地址；具体自定义前缀需选择接口格式。
- 新服务需填写自己的 Key；更改域名或端口需重新填写 Key。
- 连接恢复窗口可选择已保存服务继续；运行中不直接改写 API 配置。
- 多服务、多模型共用一个并发上限，8 并发即全局最多 8 个在途请求。累计请求数包含识别、复核、小样、目录和重试。

V1.2.7 任务台与显示：
- 顶栏左侧按钮或 Alt+T 打开任务台；纵览视图中的滚轮仅滚动，单图视图通过按钮主动选择。
- 待处理包含未识别成功和已有框待复核，卡片显示实际原因；可人工确认现有有效框，原自动判断保留在导出清单中。
- Alt+L 切换类别名称，Alt+B 切换全部标注；右侧工具栏和任务台也有按钮。仅影响预览，标注数据和导出不变。
- 底栏保留简短状态、在途数与请求速率，点击右下角展开完整统计和状态路径。
- 修复设置面板空白、重复滚轮监听，以及视图切换/缩放后的标注层错位。

V1.2.7 人工标注：
- 右侧“人工标注当前图片”或点击任务台图片进入编辑器，无需先调用 AI。
- R / W 标注：左键拖动画矩形，可连续画框；V 选择：拖动移动、八个控制点缩放。
- Ctrl+Z 撤销；Ctrl+Y / Ctrl+Shift+Z 重做；Delete 删除；Ctrl+D 复制；右键可改类、复制和删除。
- 画布滚轮切换类别；选择模式下同时修改选中框。1–9 / 0 快选前十类。
- 方向键按原图 1 像素微调，Shift 为 10 像素；A/D 切图；Esc 取消拖动或当前工具。
- 全局类别支持添加、改名、删除，作用于整个任务和人工示例。删类保留未分类框，可撤销；重新添加同名类别不会静默归类。
- 未分类框留在待处理，保存完整坐标，不生成有效 YOLO 行；选择现有类别后可确认正常图。
- 兼容 V1.2.5 可恢复任务包。Ctrl+S 保存可恢复任务包；关闭程序前先保存。最近 60 次撤销记录保留在本次会话，重新导入任务后清空。
